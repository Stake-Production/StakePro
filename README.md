# Stake Bonus Claim Website

A pixel-perfect frontend clone of the Stake bonus claim website.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Pages

- `/` - Loading screen that redirects to `/bonus`
- `/bonus` - Main bonus claim page with Stake.com and mirror sites
- `/signin` - Sign-in page with email/password form
- `/signin/code` - Sign-in page with code input

## Features

- Dark theme matching the original design
- Responsive layout
- Smooth animations and transitions
- Pixel-perfect styling with exact colors and spacing
